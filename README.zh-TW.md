# SanaCkoala

《殺戮尖塔 2》的角色 mod，新增兩個可玩角色：無尾熊和熊貓，另外還有一位等著被找到。角色都能單人玩，多人連線時也能互相配合。

Steam 工作坊：[SanaCkoala](https://steamcommunity.com/sharedfiles/filedetails/?id=3835466853)

## 角色

### 無尾熊

70 HP。起始遺物「尤加利葉」，每場戰鬥開始獲得 3 層睡意。歐洛巴斯之觸會把它升級成「尤加利花冠」（6 層睡意）。

- **睡意**：回合結束時，獲得等同睡意層數的格擋。
- **醒來**：部分卡牌會一次移除全部睡意，換成強力效果。
- 三條主線：以睡意守住節奏的「冬眠堡壘」（睡眠債、夜間守望、堡壘午睡）；儲存睡意後一次引爆的「鬧鐘爆發」（鬧鐘演練、再睡一次、粗魯鬧鐘）；以及精準安排手牌位置的「夢境／保留」（夢境日誌、夢境之門、深層劇本）。

### 熊貓

80 HP。起始遺物「竹籃」，每場戰鬥開始獲得 3 根竹子。歐洛巴斯之觸會把它升級成「野餐竹籃」（6 根竹子）。

- **竹子**：用卡牌和能力收集的資源。
- **啃 N**：手上有 N 根以上竹子時，卡牌會吃掉 N 根，觸發額外效果。
- 四條主線：用第一次啃觸發的「吃飽」安排菜單（試吃、便當、第二道菜）；把格擋轉為反擊（軟著陸、反擊蜷縮、肚皮要塞）；累積力量後打多段攻擊（熊掌練習、蛋白飲、熊掌節奏）；或累積並消耗「翻滾」動量（起滾、下坡、彈珠熊貓）。

### ？？？

塔頂上好像有誰在等。帶無尾熊和熊貓上去看看，就知道是誰了。而那可能還不是最後一雙爪子。

每個角色有 87 張卡，包含 3 張基本、20 張普通、36 張罕見、26 張稀有和 2 張先古，分配和原版角色相同。起始遺物以外，每個角色另有 7 個遺物和 3 瓶藥水（普通、罕見、稀有各一瓶）。

## 先古卡與事件

- 「古老牙齒」會把打盹變成呼呼大睡，把採竹子變成竹林豐收。
- 「積塵古籍」給無尾熊的是慵懶星期天，給熊貓的是滾滾雷霆。
- 有 12 個事件只在隊伍裡有無尾熊或熊貓時出現：雙人野餐、最後一顆餃子、尤加利收費亭、蜜糖蜂巢（第 1 幕），一起看星星、借來的吊床、竹材鑑定師、雨天爭論（第 2 幕），小吵架、夢境交換所、山頂野餐（第 3 幕），以及大頭貼機（任何一幕）。共用投票事件需要兩人以上。

## 回憶相簿

主選單多了**回憶相簿**按鈕，裡面是成就相簿：56 個成就分成 7 頁（旅途、無尾熊、熊貓、兩個隱藏頁、同行、收藏）。其中 45 個單人就拿得到，另外 11 個要在多人對局達成，隊友是誰、玩什麼角色都算。

- 成就分銅牌、銀牌、金牌，分別算 1、2、3 點，共 109 點。要累計次數的成就會顯示進度條，做到 70% 時標上「快完成了」。有 3 個是隱藏成就，達成前看不到內容。
- 達成時畫面上方會跳出帶獎牌的提示，相簿按鈕亮起紅點，下次打開相簿時新的格子會跳出來。
- 有一頁會保持隱藏，直到你找到它的主人。
- 每局結算畫面會列出這局拿到的成就（最多 3 個），以及快完成的成就（最多 3 個）。
- 點數到 20、45、70、109 點時，相簿會換新背景，相簿按鈕旁也會出現一枚別針。金牌成就會給一個稱號，顯示在相簿最上方。
- 成就只做紀念，不會改變卡牌、獎勵、事件或戰鬥。成就由全隊共享，存在每位玩家各自的進度檔。

## 安裝

在 Steam 工作坊訂閱即可。這個 mod 需要 [BaseLib](https://steamcommunity.com/sharedfiles/filedetails/?id=3737335127)，訂閱時 Steam 會提示一起訂閱。

- 多人連線時，每位玩家都要裝同一個版本。
- 不要另外在遊戲的 `mods` 資料夾放一份手動安裝的版本。
- 有 mod 時遊戲使用另一組存檔，不會動到原本的進度。
- 在全新的 mod 存檔上，原版會跳過第一章的先古之民 Neow，第一個寶箱也會給每位玩家同一個教學遺物。這個 mod 會保留 Neow，教學遺物只給其中一位玩家。

只在遊戲 v0.107.1 測試過。

## 從原始碼建置

需要：

- .NET 9 SDK
- MegaDot 4.5.1（Godot 4.5.1 mono），用來匯出 `.pck`
- 已安裝《殺戮尖塔 2》

在 `Directory.Build.props` 設定 `GodotPath`；如果找不到遊戲，再設定 `Sts2Path`。這個檔案存的是本機路徑，所以不進 git。

```bash
dotnet publish SanaCkoala.csproj
```

`dotnet build` 會把 DLL 複製到遊戲的 `mods/SanaCkoala`。`dotnet publish` 另外匯出含圖片和文字的 `SanaCkoala.pck`。

mod id 是 `SanaCkoala`。C# 命名空間和卡牌 id 保留原本的 `SpireDuo` 前綴，舊版存下的對局仍然讀得到。

想在沒解鎖時測試隱藏角色，啟動遊戲前設定環境變數 `SANACKOALA_UNLOCK_ALL=1`。設定 `SANACKOALA_ALBUM_ALL=1` 會讓回憶相簿全部顯示成已達成，但不會寫檔。開發者主控台指令 `sanackoala_achievement <ID>` 會直接達成一個成就，`sanackoala_achievement unseen` 重播揭曉動畫，`sanackoala_achievement reset` 清除成就與統計（隱藏角色維持解鎖）。

## 專案結構

| 路徑 | 內容 |
|---|---|
| `SpireDuoCode/Character` | 角色、卡池、遺物池 |
| `SpireDuoCode/Cards` | 所有卡牌 |
| `SpireDuoCode/Powers` | 睡意、竹子等能力 |
| `SpireDuoCode/Progress` | mod 自有進度檔、成就與回憶相簿 |
| `SpireDuoCode/Relics` | 起始遺物、角色遺物與共用遺物 |
| `SpireDuoCode/Potions` | 角色藥水 |
| `SpireDuoCode/Events` | 12 個事件 |
| `SpireDuoCode/Patches` | Harmony 補丁，處理全新 mod 存檔、升級版起始遺物、古老牙齒和商店角色圖 |
| `SanaCkoala/localization` | `eng`、`zht`、`zhs` 三種語言的文字 |
| `SanaCkoala/images` | 卡圖、圖示、角色圖 |
| `tools/gen_localization.py` | 產生全部語言檔，`zhs` 由 `zht` 轉換 |
| `tools/install_art.py` | 把原始圖縮成 mod 需要的尺寸並放進圖片資料夾 |
| `tools/set_workshop_description.py` | 依語言更新工作坊說明 |
| `workshop/` | Mega Crit ModUploader 用的工作坊上架資料夾 |

要改文字請改 `tools/gen_localization.py`，不要直接改 JSON，改完執行：

```bash
python tools/gen_localization.py .
```

## 發布到工作坊

每次更新都要有英文和繁體中文兩份說明。

1. 更新 `workshop/workshop.json`（英文說明，以及中英文各一段列點的更新紀錄）和 `workshop/description.zh-TW.txt`。
2. 把 `SanaCkoala.json` 的 `version` 加一版，執行 `dotnet publish`，再把 DLL、`.pck`、`.json` 複製到 `workshop/content`。
3. 用 ModUploader 上傳。它會從 `workshop/mod_id.txt` 讀作品 ID，並上傳英文說明。
4. 上傳中文說明：

```bash
python tools/set_workshop_description.py <ModUploader 資料夾>
```

加上 `english tchinese` 參數會同時更新兩種語言，不會重傳 mod，也不會新增更新紀錄。
